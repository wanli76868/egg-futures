| 项 | 内容 |
|---|---|

| **状态** | **`HYPOTHESIS`**（待验证，未进入正式策略层） |
| **命题** | 换月窗口内，**"板块合计 Δ名义持仓价值"不是一个可解释的量** —— 它同时包含"迁出月减仓"与"迁入月增仓"，两者是**同一批筹码的搬家**，不是净新增。任何据此得出的"全盘做多/做空"结论**必须先剔除迁出月**。 |

## R42 · 尾部情景「已实现」⇒ 次一时段主判方向不得低于该情景强度

| 项 | 内容 |
|---|---|
| **Rule ID** | **R42** |
| **提出日期** | 2026-09-23（11:35 午间研判） |
| **状态** | **`HYPOTHESIS`**（待验证，未进入正式策略层） |
| **命题** | 当上一份报告**明确列出的尾部风险情景**，在**次一交易日的早盘**被验证为「**已实现**」（即该情景描述的方向已经发生、且幅度达到其隐含阈值）时，**下一时段（下午）的主判断方向应至少不低于该情景的方向强度** —— 不得因为"该情景只占 26–30% 概率"而把主判断留在中性桶。 |
| **触发证据（2026-09-23 11:30 上午收盘）** | ① **09-22 全天总结**给出尾部情景 *"2611 尾盘吐仓延续 → 早盘跌破 3,845 并继续吐仓"*（概率 **26–30%**），主判为 **横盘 38 / 偏强 34 / 偏弱 28**；② **09-23 上午实际**：JD2701 **−1.11%**（远超"横盘"桶的 ±0.30% 边界）、板块等权 **−0.329%**、**7 跌 1 涨**、JD2611 由上半场 +5,651 吐回至 **−121**（吐回 100%+）→ **尾部情景的主语（吐仓）与方向（下行）均兑现**；③ 跨期看，**这是连续第 2 期"识别了风险信号但没给够权重"**（09-23 10:30 已就 09-23 早盘预判指出一次）。 |
| **与既有规则关系** | ① **强化** 09-23 10:30 提出的待验证项 *"主力月双峰双吐 ⇒ 次日早盘主判断不高于横盘"* —— 本期实测该上限**仍然偏松**（实际为偏弱），故本规则把上限从"横盘"改为"**不低于该情景方向**"，即允许并鼓励直接输出"偏弱"；② **与 R38 正交**：R38 管"偏空侧是否应下调"，R42 管"尾部情景兑现后是否应上调偏空侧权重"，两者**不冲突**（R38 本期不触发）。 |
| **Implementation** | 报告层在【自审 · 自纠】「上期错在哪」一行**必须显式回答**：「上一份的尾部情景是否已实现？」（三值：已实现 / 部分实现 / 未实现）；已实现时，【结论层】主判**不得落在与情景相反或中性的桶**，须在§0 裁决中给出理由。 |
| **验证条件** | ① 连续 **≥10 期**记录「上一份尾部情景是否实现（三值）」与「本时段实际方向桶」的 2×3 列联表；② 单独统计"已实现"子样本中，本规则要求的"方向不低于情景强度"的**顺从率**。 |
| **升格 / 否决判据** | 若"已实现"子样本中顺从率 **>70%** 且**不显著提高误判率**（即被证伪率不升）→ 升 `TESTING`；若顺从后**误判率上升**（说明尾部情景的"兑现"多为噪声）→ **REJECTED**。 |
| **⚠️ 禁止事项** | ① 不得用本规则**替代**五维因子打分与资金面交叉验证（它只调整**权重分配**，不产生新证据）；② 不得据此给出**任何做空动作**（用户只做多；方向下调仅体现为"空仓观望 / 防守减仓"）；③ 不得把"尾部情景未实现"反向解读为"主判断可以更乐观"（本轮无证据）。 |
