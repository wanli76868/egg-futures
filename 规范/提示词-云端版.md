## 一、先结论：云端任务没法从桌面端建

已实测确认，不是猜测：

| 验证项 | 结果 |
|---|---|
| 桌面端 `automation_update` 建任务返回的 ID | **UUID 形式**（如 `d9bf2fce-9c1f-…`），并自动绑定本地工作目录 `cwds` |
| 本地调度器日志 | `[LocalAutomationScheduler] started …` —— **只在桌面客户端运行时触发** |
| 云端任务 ID 形态 | **`cloud:<task_id>`** 形式（如 `cloud:1637681` / `cloud:8606800`）。⚠️ **2026-09-17 纠正**：经 `mcp__wb-issues__automation_create` 项目级通道创建的任务，**桌面端可见、可列、可触发**；旧结论"桌面端只能读不能创建"仅对更早在小程序侧建的任务成立 |
| 本地配置文件（settings.json 等） | 无任何云端自动化写入配置 |

**云端任务的唯一入口**：WorkBuddy 小程序的「云上模式 → 自动化」，或 App 的「云端工作 → 自动化」。
桌面客户端的自动化页面建的永远是本地任务。

· 合约乘数 = 10：鸡蛋 1 手 = 5 吨 = 10 个 500kg → 每 1 元/500kg = 每手 10 元

· 禁止纯价格/纯技术分析，所有结论必须由因子驱动，走 fact → data → reasoning → conclusion 链条

    · 结构判断：收盘<VWAP5 且 VWAP5>VWAP10 → 空头结构；收盘>VWAP5 且 VWAP5>VWAP10 → 多头结构

 1. 次时段/明日大概率方向 + 概率（如：偏多 62%）
 2. 最强 3 个驱动因子（排序 + 一句话因果）
 3. 关键价位（支撑/压力）与风险触发点
 4. 【持仓成本线 · 固定栏】结论
    · 哪些合约收盘在成本线上方/下方 → 近一周进场资金普遍浮盈还是浮亏
    · 把 VWAP5 / VWAP10 转成具体的支撑位与压力位数值，**两条线都要给并注明到达顺序**
      （价格在成本线上方 → 该位置易成支撑；在下方 → 反弹到该位置易遇解套抛压；
       远月常见 VWAP10 低于 VWAP5，即反弹先撞 10 日线）
    · 三周期排列是否说明短中期成本结构被破坏
