## 二、我需要 AI 帮我做什么（需求清单 · 硬性）

这八条是**不可违背的固定偏好**，任何建议违反即视为无效：

1. **禁止纯价格 / 纯技术分析** —— 所有结论必须走 `事实 → 数据 → 推理 → 结论 → 动作`；技术位最多作辅助权重，**上限 15%**，且禁止单独成结论。
2. **只做多** —— 研判偏空时，输出必须是「空仓观望 / 防守减仓」，**严禁出现做空、卖开、空单**。
3. **止损优先于止盈** —— 任何建仓建议必须**同时给出止损位与最大亏损金额（元）**；单笔止损 ≤ 权益的 2.5%（约 490 元）。
4. **风格 = 1–2 日短线 + 左侧** —— **等跌买、反弹卖**；买点给"左侧低分位区间"，**禁止"突破后追入"**；卖点给"左侧止盈"，不预设趋势。每条建议必须标注**预期持有天数**与**第 2 日复盘规则**。
5. **要可执行参数** —— 综合概率 ≥58%（或存在权重 ≥7% 的主导因子）时，必须给出东方财富期货 App 的**条件单参数**（触发价 / 委托价 / 手数 / 有效期）。
6. **早盘常无法盯盘** —— 条件单要按「**无人值守**」设计：固定价位止损止盈 + 指定时间平仓兜底 + 失效联动；**禁用回撤 / 反弹平仓单**（盘前基准会是昨收，开盘第一秒就被扫平，已实证）。
7. **量化要给分位与距离** —— 一律给 **12 日 / 60 日区间中的分位**，以及**距关键位多少点**，不要只说"高位 / 低位"。
8. **持仓关联** —— 每条建议要落到**我现在实际持有的合约与手数**上；空仓时改给「重新入场条件」。

## 五、读报告前必知的口径（否则会误读）

| 术语 | 白话解释 / 口径 |
|---|---|
| **涨跌口径** | `收盘价 − 上一交易日结算价`（**不是** 今天收盘 − 昨天收盘） |
| **结算价** | 交易所的"盯市账面价"（当日成交量加权均价）。**次日无法按结算价成交** —— 大跌日 84.8% 的情况收盘价低于结算价 |
| **VWAP3 / 5 / 10** | 近 3 / 5 / 10 个交易日**结算价**按成交量加权 = 这一周 / 两周进场资金的**平均成本**。价格在其上方 → 该线易成支撑；在下方 → 反弹到该线易遇解套抛压 |
| **沉淀资金** | `持仓量 × 最新价 × 10`。期货**没有"净流入"**，只跟踪沉淀资金的变化 |
| **四象限** | 涨+增仓＝多头进场；涨+减仓＝空头平仓（**反弹勿追**）；跌+增仓＝空头进场（**不抄底**）；跌+减仓＝多头平仓（抛压衰竭） |
| **席位 T-1** | 龙虎榜（前 20 席位）数据**恒滞后 1 日**，且历史不可回补；**判当日方向以盘中持仓量变化为主**，席位只作背景（权重 3%） |
| **贴水 / 基差** | 基差 = 现货(元/500kg) − 期货收盘。换算：**现货 元/斤 × 1000 = 期货口径 元/500kg** |
| **合约乘数** | 10。1 手 = 5 吨 = 10 个 500kg → **每 1 元/500kg = 每手 10 元** |
| **浮盈亏** | `(最新价 − 开仓成本) × 10 × 手数` |

## 六、数据源与已知边界

- **唯一权威**：**大商所官方日行情 xlsx**（桌面「历史日线数据」，2013-11-08 上市首日起，155 个合约）→ 已建成主数据集 `jd_master.json`（36,200 行）。
- ⚠️ **新浪历史日线不可用于结算价 / VWAP / 成本线** —— 2019–2021 存在"半日快照"污染（成交量恰为官方一半、结算价为 0）。
- ⛔ **大商所官网在本机三重封锁不可达**（412 / WAF），不要再尝试。
- **免费源边界**：单月合约历史最早只到 **JD1904（2018-04）**；2013–2018 的**单月**合约靠官方 xlsx 补齐，但 **KD 主力连续**曲线可用。
- **统计锚（13 年官方）**：大跌次日无延续（N=1,521，跌≥2% 次日均值 +0.46%）；9 月中旬（9/11–9/20）胜率 58.3%；**周度结算周期对"方向"无效（eta²=0.0011）但对"风险"有效** —— 周末跳空 0.643% vs 隔夜 0.469%，长假 1.209%。

## 七、给 AI 的使用建议

- 想回答"**现在能不能买 / 怎么处理某合约**" → 先读 `知识库` 里**最近一个交易日**的「全天总结」或「午间研判」，它们的【结论层】有**11 个合约逐个的方向 + 概率 + 关键压力/支撑**和【重新入场条件】。
- 想理解"**他为什么要这么算**" → 读 `规范/` 那份 + `2026-09-18 研究整合`。
- 给建议前**务必对照第二节的八条偏好**自查（尤其：只做多、左侧、止损金额、1–2 日）。
