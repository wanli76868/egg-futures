## 二、我需要 AI 帮我做什么（需求清单 · 硬性）

这些是**不可违背的固定偏好**，任何建议违反即视为无效：

1. **禁止纯价格 / 纯技术分析** —— 所有结论必须走 `事实 → 数据 → 推理 → 结论 → 动作`；技术位最多作辅助权重，**上限 15%**，且禁止单独成结论。
2. **只做多** —— 研判偏空时，输出必须是「空仓观望 / 防守减仓」，**严禁出现做空、卖开、空单**。
3. **止损优先于止盈** —— 任何建仓建议必须**同时给出止损位与最大亏损金额（元）**；单笔止损 ≤ 权益的 2.5%（约 490 元）。
   **止损三段式**：结构位定距离 → 噪声下限校验（S ≥ 0.95% ≈ 33 点）→ **手数让路**（`手数 = floor(风险预算 ÷ (S × 10))`）。**禁止**"止损 X 点 = 亏损 Y 元"这类倒推写法。
4. **风格 = 短线 + 左侧** —— **等跌买、反弹卖**；买点给"左侧入场带"（结构位 + 噪声下限反推），**禁止"突破后追入"**；卖点给"左侧止盈"，不预设趋势。
   ⚠️ **持有期 ＝ 事件驱动退出，不写死天数**；N = 3–5 交易日是**复核触发器**，不是平仓令。
5. **要可执行参数** —— 给机会必须同时给 `p̂ > p_min = (S+c)/(T+S)`（c ≈ 4 点双边成本）、`R = T/S`、手数、**最大亏损(元)**。
   🔴 原「≥58% / ≥7%」门槛**已作废**（出处不明且与"1:3 盈亏比"自相矛盾），不得再引用。
6. **早盘常无法盯盘** —— 条件单要按「**无人值守**」设计：固定价位止损止盈 + 指定时间平仓兜底 + 失效联动；**禁用回撤 / 反弹平仓单**（盘前基准会是昨收，开盘第一秒就被扫平，已实证）。
7. **量化要给分位与距离** —— 一律给 **12 日 / 60 日区间中的分位**，以及**距关键位多少点**，不要只说"高位 / 低位"。
   关键压力 / 支撑**一律用量化位**，禁用"当期今高 / 今低"作判定依据。
8. **持仓关联** —— 每条建议要落到**现在实际持有的合约与手数**上；空仓时改给「重新入场条件」。
   盯市盈亏按**结算价**、可变现盈亏按**最新价**，两者必须分别给出。

## 五、读报告前必知的口径（否则会误读）

| 术语 | 白话解释 / 口径 |
|---|---|
| **涨跌口径** | `收盘价 − 上一交易日结算价`（**不是** 今天收盘 − 昨天收盘）；`\|涨跌\| ≤ 0.1%` 按平收处理（用未舍入值） |
| **结算价** | 交易所的"盯市账面价"（当日成交量加权均价）。**次日无法按结算价成交** —— 跌 ≥2% 的 201 个交易日中 181 日收盘低于结算价 |
| **成交成本锚点（VWAP3 / 5 / 10）** | 近 3 / 5 / 10 个交易日**结算价**按成交量加权，意思是"这几天买的人大概花的什么价"。⚠️ **不是"持仓者的平均成本"**。价格在其上方 → 该线易成支撑；在下方 → 反弹到该线易遇解套抛压 |
| **名义持仓价值** | `持仓量 × 最新价 × 10`。期货**没有"净流入"**，只跟踪名义持仓价值的变化；须注明 `Δ名义价值 = OI 效应 + 价格效应 + 交叉项` |
| **四象限** | **去主语的结构信号**（无逐笔数据，"谁主动"不可证）：涨+增仓＝持仓扩张；涨+减仓＝持仓收缩（**反弹勿追**）；跌+增仓＝**勿抄底**；跌+减仓＝离场。⚠️ 四象限**不得作为买入理由** |
| **单合约贡献度** | 板块资金变化必查最大贡献合约占比：**>60% 须单列**、**>100% 判"假流入"**。已连续多期出现"剔除最大正贡献后符号翻转" |
| **席位基准日** | 龙虎榜（前 20 席位）为**会员口径**，客户类型为推测。⚠️ 接口**自 2026-09-18 起长期冻结** → 报告**只写绝对基准日**，**禁写"T-1 / T-2"相对值**，权重 ≤3% |
| **贴水 / 基差** | 基差 = 现货(元/500kg) − 期货收盘。换算：**现货 元/斤 × 1000 = 期货口径 元/500kg** |
| **合约乘数** | 10。1 手 = 5 吨 = 10 个 500kg → **每 1 元/500kg = 每手 10 元** |
| **浮盈亏** | `(最新价 − 开仓成本) × 10 × 手数`；盯市用**结算价**、可变现用**最新价** |

## 六、数据源与已知边界

- **唯一权威**：**大商所官方日行情 xlsx**（桌面「历史日线数据」，2013-11-08 上市首日起，155 个合约）→ 已建成主数据集 `jd_master.json`（36,200 行）。
- ⚠️ **新浪历史日线不可用于结算价 / VWAP / 成本线** —— 2019–2021 存在"半日快照"污染（成交量恰为官方一半、结算价为 0）。
- ⛔ **大商所官网在本机三重封锁不可达**（412 / WAF），不要再尝试；akshare / 生意社 / 金投网同样已穷尽。
- **本机网络特征**：走本地代理（fake-IP 段 `198.18.x.x`）+ **域名白名单且波动** → 每个报告时点前**必须复跑** `python scripts/source_doctor.py`（退出码 2 ＝ 有关键源缺失）。
- ⭐ **`github.com` 的 git 协议被挡，但 `raw.githubusercontent.com` 的 HTTPS 可直连** → 取 GitHub 单文件走 `curl` raw，不要 `clone`。
- **免费源边界**：单月合约历史最早只到 **JD1904（2018-04）**；2013–2018 的**单月**合约靠官方 xlsx 补齐，但 **KD 主力连续**曲线可用。

### 统计锚（只列仍有效的）

| 锚 | 结论 |
|---|---|
| **唯一稳健 Edge** | 9 月中旬（9/11–9/20）Lift **+6.9pct**（逐合约池 +0.395 / 按日去重 +0.292）—— ⚠️ **已出窗口** |
| **追涨负期望** | 涨 ≥1% 次日胜率 **42.7%** vs 无条件基线 **47.0%** → **禁突破追入** |
| **结算价不可成交** | 跌 ≥2% 的 201 日中 **181 日**收盘低于结算价 |
| **周度方向无效** | 星期效应 **eta² = 0.0003** → **禁"周几偏多/偏空"** |
| **跳空风险** | 普通隔夜 0.448% ｜ 周末 **0.600%**（P>1% ＝ 13.4%）｜ **长假后 2.184%** |
| **日历纪律** | 周一不在开盘方向反面逆势开仓；跳空高开不追入；**大幅低开当日不抄底**（买点推迟到周二–周三） |
| **默认输出** | **WAIT / IGNORE** —— 系统必须学会"不交易"，「今天没有机会」是有效输出 |

🔴 **已作废、禁止引用**：大跌后次日锚 ｜ 大涨日回抽 93.1%（缺 Baseline 的假发现）｜ 加仓前置② ｜ **左侧低分位（分位低不是入场理由）** ｜ 振幅位置 ｜ 高换手 ｜ 涨+增仓。

## 七、给 AI 的使用建议

- 想回答"**现在能不能买 / 怎么处理某合约**" → 先读 `知识库` 里**最近一个交易日**的报告（全天总结 / 午间研判 / 盘中资金），它们的【结论层】有**可交易池内合约的方向 + 概率 + 量化关键位**和【标的池与入场 / 重新入场条件】。
  ⚠️ 旧「11 合约逐个预判」**已作废** —— 池外合约严命中率虚高 14.3pp，现**只预判可交易池**，池外合并为一行。
- 想理解"**他为什么要这么算**" → 读 `规范/` 那几份 + `2026-09-18 研究整合`。
- 想知道"**哪些规则已被证伪**" → 读 `规范/规则变更日志.md`（append-only，每条都带触发证据与证据强度）。
- 给建议前**务必对照第二节的八条偏好**自查（尤其：只做多、左侧、止损金额、事件驱动退出）。

### 报告结构权威

报告正文的**结构与命名唯一权威**是一份本地技能（`lark-report-delivery`，当前 **v8.11**），不在本仓库内。

**报告体量（精要版为默认 · 2026-09-28 用户裁定）**：正文 **表外有效字**（＝剔除表格行后的中文＋字母＋数字＋%）—— 全天总结 / 午间 / 尾盘 **≤3,200**、盘中 **≤2,000**；**附录 A/B/C/D 一律不输出**。基线＝`2026-09-28 早盘预判精要` 的 **3,176 字 / 约 7.9 分钟**（比旧完整版压缩 **79.5%**）。

骨架要点：
阅读卡 → 速览卡 → 决策卡 → **【自审·自纠】** → 事实层（Delta → 对照表 → 五维因子 → 因子有效性 → 龙虎榜 → 成本/估值锚 → 突发 5 问 → 成本线固定栏）→ 结论层（**§0 多空对抗 + 风控一票否决** → 可交易池预判 → 最强 3 因子 → 量化关键位 → 持仓状态 → 处置与挂单 → 标的池与入场）→ **【机构观点速览】** → **【交叉验证】** → **【科普·今日一条】** → **【本期自进化】** → 附录。
⚠️ 正文**禁出现 H1**（会被当文档标题，导致云文档与知识库节点名双路被改）。
